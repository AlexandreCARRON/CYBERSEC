# Paquet Metatron

- `policy.py` valide l'autorité et la cible ;
- `planning.py` produit les plans content-addressed ;
- `runner.py` impose les checkpoints ;
- `tools.py` contient les adaptateurs fermés ;
- `assistant.py` limite l'IA à Ollama local ;
- `audit.py` journalise uniquement des métadonnées.
